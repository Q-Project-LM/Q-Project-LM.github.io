JEV

JEV — вторая модель (47 МБ), работает в отдельном потоке. Она хорошо отличает ответ по делу от ответа не по теме (98% на тесте), но не проверяет, верны ли числа и факты.JEV is a second model (47 MB) running in its own thread. It tells an on-topic answer from an off-topic one well (98% on the test set), but it does not check whether numbers or facts are right.JEV 是第二个模型（47 MB），在独立线程中运行。它能很好地区分切题和不切题的回答（测试集 98%），但不检查数字或事实是否正确。

Размышления и выражения для инструментов декодируются жадно, видимый ответ — с выбранной температурой; размышления ограничены 128 токенами. По умолчанию каждое сообщение решается с чистого контекста: 26M-модель плохо держит длинный диалог — прошлые ответы сбивают её.Thinking and tool expressions are decoded greedily, the visible answer at the chosen temperature; thinking is capped at 128 tokens. By default each message is answered from a clean context: the 26M model holds long conversations poorly — earlier answers throw it off.思考过程和工具表达式使用贪心解码，可见回答使用所选温度；思考限制在 128 个词元以内。默认情况下每条消息都从干净的上下文回答：26M 模型不擅长长对话 —— 之前的回答会干扰它。

🧪Экспериментальный чат. Кроме чат-модели здесь работает вторая модель — JEV: она проверяет каждый ответ, при необходимости просит перегенерировать его и помечает запросы. Всё, что она делает, видно на плашках «JEV». Отключить — в настройках (⚙) или нажав на «JEV» вверху.Experimental chat. Besides the chat model, a second model runs here — JEV: it checks every answer, asks for a regeneration when needed and tags requests. Everything it does is shown on the "JEV" chips. Turn it off in settings (⚙) or by clicking "JEV" at the top.实验性聊天。除了聊天模型，这里还运行着第二个模型 —— JEV：它检查每个回答，必要时要求重新生成，并给请求打标签。它做的一切都显示在"JEV"标签上。可在设置（⚙）中关闭，或点击顶部的"JEV"。

N-Q-26M-Chat

Маленькая русско-английская модель, обученная с нуля на одной V100. Работает прямо в этой вкладке. Точные вычисления делает исполнитель — их видно как отдельные плашки.A small Russian/English model trained from scratch on one V100, running right in this tab. Exact computation is done by an executor — you'll see it as separate chips.一个在单张 V100 上从零训练的小型俄英双语模型，直接在这个标签页里运行。精确计算由执行器完成 —— 会以单独的标签显示。

26M параметров: часто путает факты и зацикливается. Работает локально, ничего не отправляется на сервер.26M parameters: often gets facts wrong and loops. Runs locally — nothing is sent to a server.26M 参数：经常弄错事实、陷入重复。在本地运行 —— 不会向服务器发送任何内容。
