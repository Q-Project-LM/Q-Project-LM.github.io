Chat with Q-164M

A from-scratch, text-only member of the Q architecture family: ternary weights, a frozen fingerprint vocabulary, and a generalized exact-tool-calling mechanism — arithmetic, dates, sorting, filtering, even chained multi-step lookups — running natively in this tab, no server involved. Tool calls are shown here, not hidden, so you can see when the network hands off to the deterministic executor.

Try: What is 347 times 86? · An item costs 800 dollars with a 20 percent discount — what's the final price? (a chained, two-step tool call) · How many days between January 1 and March 15, 2026? · Sort these: 9, 3, 7, 1. Or just say hi — it's a normal chat too. Decoding is forced greedy, matching the setup the exact-match accuracy was measured with; unusual phrasings can still make the model reach for the wrong tool, or none at all — that failure mode is real and not hidden here.
